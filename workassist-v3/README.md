# WorkAssist v3

> **초경량 초고속 오프라인 업무 보조 플랫폼**
> **Powered by Tauri v2, Rust Core & SQLite WAL**

WorkAssist v3는 **압도적인 오프라인 속도와 초경량 컴퓨팅 파워**를 핵심 가치로 설계된 현대적인 데스크톱 업무 보조 시스템입니다. 미사용 오프라인 벡터/RDF DB 엔진(LanceDB, Oxigraph, ONNX Runtime) 및 수주/제품DB를 완전 박리하여, 리소스 낭비 없는 컴팩트한 코어 시스템을 확립했습니다.

---

## 🛠️ 핵심 탑재 기능군 (v3 Compact Core)

1. **📊 비즈니스 종합 대시보드 (Dashboard)**:
   - 진행 중인 업무 상태(Note, To-do, Doing, Done) 비율을 아름다운 프리미엄 Dracula HSL 도넛 차트로 자동 시각화합니다.
   - 마감 기한이 초과되었거나 3일 이내 임박한 태스크들을 우선순위 D-day 펄스 배지와 함께 정밀 노출합니다.
   - 부서별 업무 강도(이슈 건수 / 계획 일수)를 가로형 바 그래프 차트로 가시화합니다.

2. **📋 칸반 업무 관리자 (Kanban Board & Gantt Timeline)**:
   - Drag & Drop 방식의 현대적인 4단계 상태 파이프라인 칸반 카드를 제공합니다.
   - 시작일과 마감일을 날짜 좌표로 매핑하는 Gantt 스케줄 뷰와 월별 Monthly 달력 캘린더 격자 뷰를 교환 지원합니다.
   - 실수로 지운 카드를 무결히 살릴 수 있는 소프트 딜리트(Soft Delete) 안심 휴지통 버퍼를 탑재하고 있습니다.

3. **📝 회의록 관리자 (Minutes Manager)**:
   - 타일형 카드 보드와 캘린더 뷰를 교환하며 회의 안건, 결정 사항, 참석자 정보를 자산화합니다.
   - 카테고리 삭제 시 기존 작성된 회의록들이 격리되지 않도록 `ON DELETE SET NULL` 데이터 참조 무결성(Cascade)을 확보했습니다.
   - 개별 및 전체 회의록을 단번에 마크다운(MD) 파일군으로 내보내고 저장할 수 있습니다.

4. **🏗️ 프로젝트 관리자 (Project Pipeline & Time Table)**:
   - 부서별 협업 진척 상태를 4개의 커스텀 수직 상태 로그 기둥으로 구성하여 제어합니다.
   - Weekly & Monthly 조절 Gantt 차트를 HTML/MD 보고서 파일로 즉시 출력할 수 있습니다.
   - 최대 20개의 마일스톤 데드라인 추적 및 완료 프로젝트 안전 보관 기능을 장착했습니다.

5. **⚙️ 모터사양 및 토크 계산기 (Motor Specs & Torque Calculator)**:
   - **6대 회전체 물리 연산**: 회전 토크($T=J\alpha$), 관성 모멘트($J=mr^2$, 링 모양 물체 및 다중 지점 합산 보완), RPM-각속도-각가속도 다차원 상호 환산, 가속+중력 합산 부하 토크, 모터 고유 역기전력 대비 최대속도 및 요구 부하 시 필요 전류(A) 연산을 초고속 RUST 백엔드 명령어 연동으로 처리합니다.
   - **📊 실시간 60FPS 구동 프로파일 SVG 시각화**: 구동 주기 구간 편집 테이블 값을 타이핑하여 변경하거나 행 추가/삭제를 수행할 때 SVG 프로파일 그래프(속도 파랑, 토크 주황 2축 스케일링)가 60FPS 급 반응성으로 자동 렌더링됩니다.

## 🏗️ v3 초경량 아키텍처

```
                  ┌──────────────────────────────┐
                  │   WorkAssist v3 Client UI    │
                  └──────────────┬───────────────┘
                                 │
                    [Tauri IPC Bridge / Commands]
                                 │
                  ┌──────────────┴───────────────┐
                  │    Tauri v2 Rust Core        │
                  └──────────────┬───────────────┘
                                 │
                                 ▼
                     ┌───────────────────────┐
                     │ SQLite WAL Storage    │
                     │ - Tasks / Meetings    │
                     │ - Projects/Milestones │
                     └───────────┬───────────┘
                                 │
                                 ▼
                        💾 [sjworkassist.db]
```

- **SQLite WAL Single Engine**: 고성능 WAL(Write-Ahead Logging) 트랜잭션으로 단일 파일 스토리지 I/O를 제어하여 리소스 점유율을 90% 이상 절감합니다.
