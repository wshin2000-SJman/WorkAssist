# WorkAssist v2

> **오프라인 지능형 업무 보조 및 지식 데이터 통합 플랫폼**
> **Powered by Tauri v2, Rust & SQLite/Oxigraph/LanceDB Multi-Engine**

WorkAssist v2는 **보안성과 오프라인 구동 성능**을 최우선으로 설계된 현대적인 다크 테마 데스크톱 애플리케이션입니다. 인터넷 연결이 완전히 차단된 폐쇄망 환경에서도 로컬 컴퓨팅 파워만을 이용해 오프라인 PDF/Excel 파싱, 지식 구조화, 일정 및 칸반 협업, 지식 그래프 시각화, 모터 회전체 물리 계산 및 100% 무손실 오프라인 하이브리드 RAG 검색을 부드럽게 지원합니다.

---

## 🛠️ 핵심 탑재 기능군

1. **📊 비즈니스 종합 대시보드 (Dashboard)**:
   - 진행 중인 업무 상태(Note, To-do, Doing, Done) 비율을 아름다운 프리미엄 Dracula HSL 도넛 차트로 자동 시각화합니다.
   - 마감 기한이 초과되었거나 3일 이내 임박한 태스크들을 우선순위 D-day 펄스 배지와 함께 정밀 노출합니다.
   - 부서별 업무 강도(이슈 건수 / 계획 일수)를 가로형 바 그래프 차트로 가시화합니다.

2. **📋 칸반 업무 관리자 (Kanban Board & Gantt Timeline)**:
   - Drag & Drop 방식의 현대적인 4단계 상태 파이프라인 칸반 카드를 제공합니다.
   - 시작일과 마감일을 날짜 좌표로 매핑하는 Gantt 스케줄 뷰와 월별 Monthly 달력 캘린더 격자 뷰를 교환 지원합니다.
   - 실수로 지운 카드를 무결히 살릴 수 있는 소프트 딜리트(Soft Delete) 안심 휴지통 버퍼를 탑재하고 있습니다.

3. **📝 회의록 관리자 (Minutes Manager)**:
   - 타일형 카드 보드와 캘린더 뷰를 교환하며 회의 안건, 결정 사항, 참석자 정보를 자산화합니다.
   - 카테고리 삭제 시 기존 작성된 회의록들이 격리되지 않도록 `ON DELETE SET NULL` 데이터 참조 무결성(Cascade)을 확보했습니다.
   - 개별 및 전체 회의록을 단번에 마크다운(MD) 파일군으로 내보내고 저장할 수 있습니다.

4. **🏗️ 프로젝트 관리자 (Project Pipeline & Time Table)**:
   - 부서별 협업 진척 상태를 4개의 커스텀 수직 상태 로그 기둥으로 구성하여 제어합니다.
   - Weekly & Monthly 조절 Gantt 차트를 HTML/MD 보고서 파일로 즉시 출력할 수 있습니다.
   - 최대 20개의 마일스톤 데드라인 추적 및 완료 프로젝트 안전 보관 기능을 장착했습니다.

5. **🤖 PDF & Excel 사양 파서 (Parser & Document RAG)**:
   - calamine 파서 기반으로 엑셀 설계도나 PDF 사양서 텍스트를 오프라인에서 파싱하여 정형 데이터 및 384차원 시맨틱 벡터로 변환합니다.
   - 폴더 전체 일괄 파싱 진행 상태를 Dracula 컬러 진행 바와 3배 확대 모션 그래픽으로 안내하며, 안전 중지(Abort) 제어가 가능합니다.

6. **🗄️ 제품DB 및 수주DB 관리자 (Product & Order RDBMS)**:
   - 제품 사양 인입 전 표 셀을 더블클릭해 즉석에서 수치를 수동 조율하는 Human-in-the-loop(HITL) 데이터 교정 인터페이스를 탑재했습니다.
   - 맥락 유사도 시맨틱 질문과 RDBMS 메타 필터 조건(분류군, 제조사)을 융합 계산하는 하이브리드 필터 검색이 가동됩니다.
   - 전체 누적 매출 누계 및 계약 대장을 ₩ 통화 단위 콤마 형식으로 실시간 합산 트래킹합니다.

7. **📜 온디스크 히스토리 관리자 (History SPARQL & D3.js Graph)**:
   - 완료 프로젝트의 BOM 설계 명세서 엑셀을 calamine 파서로 읽어와 W3C RDF 글로벌 트리플 사양으로 RocksDB 기반 **Oxigraph** DB에 영구 지식화합니다.
   - 은하수 모양의 D3 Force Simulation 인터랙티브 3D 링크-노드 지식망 시각화를 통해 부품 연계성을 탐색합니다.
   - 노드 삭제 시 Oxigraph 지식 트리플 소거와 연동된 LanceDB 사양 문서 벡터 삭제를 원자적으로 처리(Cascade Purge)합니다.

8. **⚙️ 모터사양 및 토크 계산기 (Motor Specs & Torque Calculator) - *신규 추가***:
   - **6대 회전체 물리 연산**: 회전 토크($T=J\alpha$), 관성 모멘트($J=mr^2$, **링 모양 물체 및 다중 지점 합산 보완**), RPM-각속도-각가속도 다차원 상호 환산, 가속+중력 합산 부하 토크, 모터 고유 역기전력 대비 최대속도 및 **요구 부하 시 필요 전류(A) 연산**을 초고속 RUST 백엔드 명령어 연동으로 처리합니다.
   - **📊 실시간 60FPS 구동 프로파일 SVG 시각화**: 구동 주기 구간 편집 테이블 값을 타이핑하여 변경하거나 행 추가/삭제를 수행할 때, **계산 버튼을 누르지 않아도 즉각적으로 SVG 프로파일 그래프(속도 파랑, 토크 주황 2축 스케일링)가 60FPS 급 반응성으로 자동 렌더링**됩니다.

## 🏗️ 3중 경량 오프라인 스토어 아키텍처

WorkAssist v2는 고성능 단일 오프라인 저장소 기법을 도입하여 리소스 중복을 원천 차단하고 입출력(I/O) 병목을 제어합니다.

```
                  ┌──────────────────────────────┐
                  │   WorkAssist v2 Client UI    │
                  └──────────────┬───────────────┘
                                 │
                   [Tauri IPC Bridge / Commands]
                                 │
                  ┌──────────────┴───────────────┐
                  │    Tauri v2 Rust Core        │
                  └──────────────┬───────────────┘
         ┌───────────────────────┼───────────────────────┐
         ▼                       ▼                       ▼
┌─────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│  SQLite (RDBMS) │    │  LanceDB (Vector)│    │  Oxigraph (RDF)  │
│ - Tasks/Meetings│    │ - Spec Embedding │    │ - BOM Ontology   │
│ - RDBMS Specs   │    │ - Semantic Vector│    │ - Semantic Graph │
└────────┬────────┘    └────────┬─────────┘    └────────┬─────────┘
         │                      │                       │
         ▼                      ▼                       ▼
 💾 [sjworkassist.db]    💾 [specs_vectors/]    💾 [oxigraph_data/]
```

- **SQLite WAL RDBMS**: 트랜잭션 충돌을 제어하기 위해 상시 WAL(Write-Ahead Logging) 모드를 가동합니다.
- **LanceDB Vector Database**: 기기 내부 ONNX 임베딩 엔진(`all-MiniLM-L6-v2`)을 활용해 384차원 의미론적 밀도 벡터 공간을 영구 적재하고 검색합니다.
- **Oxigraph RDF Store**: W3C 표준 시맨틱 트리플 저장을 위해 고성능 RocksDB 내장형 Oxigraph 엔진을 가동합니다.

## 📦 배포 경량화 및 최적화 명세

단독 실행 인스톨러(`.exe`)의 배포 용량을 극단적으로 감축하기 위해 다음과 같은 최적화 파이프라인을 구축했습니다:

1. **에셋 용량 13.25 MB 완전 절감**:
   - `ui/assets` 폴더 내에 잔존해 있던 사용되지 않는 대용량 이미지/GIF 미사용 테스트 리소스 14개를 영구 박리 소거하여 바이너리 기본 무게를 줄였습니다.
2. **백엔드 고성능 릴리즈 컴파일 최적화 (`Cargo.toml`)**:
   - `opt-level = "z"`: 기계어 코드 크기 최소화 압축 빌드를 기동합니다.
   - `lto = true` & `codegen-units = 1`: 링크-타임 최적화를 적용해 미사용 컴파일 라이브러리 소스들을 자동 소거합니다.
   - `panic = "abort"` & `strip = true`: 디버깅용 메타데이터, 컴파일 심볼 및 스택 기록용 메타정보를 파일에서 완전 박리(Strip)하여 용량 다이어트와 보안성을 동시에 확립했습니다.

## 🛠️ 단독 실행 프로그램 설치 및 삭제 방법

사용자의 편의를 돕기 위해 **NSIS(Nullsoft Scriptable Install System)** 기반 단일 파일 설치 마법사를 탑재하여 배포합니다.

### 1. 단일 파일 설치법 (.exe)
- 배포된 **`WorkAssist_2.1.0_x64-setup.exe`** 설치 파일을 다운로드하여 실행합니다.
- **친숙한 한국어(Korean) 가이드**에 따라 동의 및 설치를 터치 몇 번으로 완료할 수 있습니다.
- 설치 모드 선택 시 **`currentUser`** 또는 **`perMachine`**에 맞춰 로컬 환경에 완벽 적재되며 바탕화면 및 시작 메뉴 단축 아이콘이 자동으로 매핑됩니다.

### 2. 깔끔한 프로그램 삭제법 (Uninstall)
- 앱 삭제를 원할 경우, 윈도우 **"설정 > 앱 > 설치된 앱 (제어판 프로그램 추가/제거)"** 항목으로 들어갑니다.
- 설치 목록 중 `WorkAssist` 항목의 우측 버튼을 누르고 **'제거'**를 클릭하면 내장된 한국어 언인스톨러 마법사가 기동되어 레지스트리 및 캐시 정보를 안전하게 원클릭 영구 제거합니다.
